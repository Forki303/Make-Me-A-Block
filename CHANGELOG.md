# Changelog

## [1.1.0] - 2026-08-18

### Added

- Skin sync: other players with the mod installed now see your block skin and your custom painted skin
- The mod now includes a small server component that forwards skins between players

### Notes

- Skin sync requires the mod on the server as well (automatic in singleplayer)
- On vanilla servers the mod still works locally, but other players won't see your skin

## [1.0.0] - 2026-08-17

### Added

- Block picker menu (press `B`)
- Block skin rendering on the avatar and first-person arms
- Skin painter with palette, brush size and eraser
- Block tinting for colored blocks
- English and Russian translations
